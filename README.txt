СМАЧНОБОРЩ - САЙТ КУЛІНАРНИХ РЕЦЕПТІВ

ОПИС ПРОЄКТУ

«СмачноБорщ» - вебсайт кулінарних рецептів, створений у межах курсової роботи з дисципліни «WEB-технології та WEB-дизайн».

Мета проєкту - надати користувачам зручний доступ до кулінарних рецептів, допомогти знаходити страви та ознайомлюватися з рекомендаціями щодо їх приготування.

ОСНОВНІ МОЖЛИВОСТІ

- Перегляд популярних кулінарних рецептів.
- Пошук рецептів за текстом карток.
- Фільтрація страв за категоріями.
- Перегляд детального рецепта з інгредієнтами та способом приготування.
- Перегляд кулінарних порад.
- Отримання випадкового рецепта через зовнішній API TheMealDB.
- Адаптивне відображення на різних пристроях.

ВИКОРИСТАНІ ТЕХНОЛОГІЇ

- HTML5 — створення структури вебсторінки.
- CSS3 — оформлення та адаптивний дизайн.
- JavaScript — реалізація інтерактивних можливостей.
- TheMealDB API — отримання випадкових кулінарних рецептів.
- Figma — підготовка макета вебсайту.
- GitHub Pages — публікація вебсайту в інтернеті.

СТРУКТУРА ПРОЄКТУ

- index.html — головна HTML-сторінка.
- css/style.css — таблиця стилів.
- js/script.js — JavaScript-код.
- img/ — папка із зображеннями.


Проєкт виконано в межах курсової роботи з дисципліни «WEB-технології та WEB-дизайн».
